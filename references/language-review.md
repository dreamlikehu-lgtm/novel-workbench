# 小说语言复查

用于每章的表达审稿，以及用户指定的语言润色、去 AI 味和全书文风复查。结合本书 `style.md`、人物声音与当前场景，找出影响阅读的具体写法。下列小说检查规范由本项目独立编写，参考缘由和许可观察见 [来源说明](sources.md#语言复查模块)。

## 检查对象与尺度

先读待审的真实正文，再对照必要的上文、摘要和事实候选。分章句段检查与邻章比较各有用途。邻章比较重点看不同人物是否同声、相似场景是否沿用同一反应，以及章末是否反复解释人物已经做出的选择。只读了局部，就按局部报告检查范围。

需要统计时写清正文范围、计数单位和实际结果。工具定位到的句子仍需逐处阅读。单次命中与整篇分布分别解释，修改建议应说明它怎样妨碍当前场景。阅读诊断按原句和位置说明依据。

## 句段与场景

| 关注点 | 复查问题 | 修订方向 |
|---|---|---|
| 叙述讲解挤占场景 | 动作与对白之后是否重复解释同一层情绪，章末是否又总结一次 | 保留读者理解行动所需的信息，精简已由场景表达的解释 |
| 人物声音趋同 | 不同年龄、关系与处境的人是否都用相同的抽象词、结论句或问答节拍 | 回到人物此刻的诉求、隐瞒和说话习惯，调整可定位的台词 |
| 句子承载过多 | 修饰语、插入说明和连续动作是否使动作主体或先后关系难以追踪 | 明确主体与动作次序，按原有信息重排或拆句 |
| 指称来回变化 | 同一人物、物件或概念换称呼后，读者是否误以为换了对象 | 使用场景内可认出的称呼，核对每个代词与别称的所指 |
| 排列过于整齐 | 相邻句或段落是否反复使用相同骨架，细节是否只在平列铺陈 | 按当下观察和行动的主次组织，保留真正改变理解的信息 |
| 连接解释过密 | 转场是否反复替读者说明已经清楚的关系，删后是否仍能跟上 | 精简多余铺垫，核对剩下的时间、地点、因果与线索仍清楚 |
| 意象与经验脱节 | 比喻的动作、感官或尺度是否彼此冲突，是否符合视角人物能想到的事物 | 结合上下文审读，保留有作用的意象，无法确定时标明待核 |

重复、直白、长句、停顿和修辞都可能承担叙事功能。审查人物口头禅、对白、引文、线索回声或刻意反复时，先说明它在场景里的作用。文风参照和人物习惯应进入判断。句长、标点与标题的数量可辅助观察节奏，修改由阅读问题决定。

## 从发现到处理

把候选归为“建议修改”“保留”“误报”或“待核”，并给出原句、位置及理由。数量只有在实际清点后填写。普通表达建议沿用 `advisory`；阻断性问题须说明它造成的理解障碍或故事矛盾。

- 用户仅要求检查时，给出范围、典型问题和拟改方向，等待后续改稿指令。
- 用户已授权写作、续写或改稿时，在约定范围内完成局部修复与复查。涉及改变人物目标、揭示顺序或故事走向时，先明确需要用户裁决的选择。
- 修订既有章节时按账本的历史分支流程处理。所有改后文本都要重新核对角色认知、时间、动作次序、物件归属和证据片段。

修改后对照原文回读，检查是否改变了否定、程度、承诺或不确定性。为补足篇幅而增加的内容，也要形成有后果的行动或必要认识。整章和邻章的节奏问题按场景调整，节奏须能服务人物与事件。

## 记录与验收

语言复查记入现有 `scope=craft` 的 `notes` 与 `findings`，沿用当前候选的四个版本标识。`notes` 写明本次阅读范围、实际发现、已处理项，以及有代表性的保留或待核理由。检查结果平稳时如实记录观察依据。

正文、摘要或事实候选改动后重新 stage，重新阅读候选，并完成两种审稿。连续写作与批量修订均按实际授权推进。来源项目的研究数字仅用于理解设计背景；本技能的验收仍以本书的具体阅读判断和现有版本检查为依据。
